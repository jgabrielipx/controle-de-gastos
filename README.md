# Controle de Gastos

Aplicação web simples para registrar despesas pessoais e acompanhar o total gasto.

## Funcionalidades

- Adicionar despesas com descrição, valor, categoria e data.
- Listar as despesas cadastradas.
- Excluir uma despesa ou limpar toda a lista.
- Calcular automaticamente o total e a quantidade de despesas.
- Salvar os dados no navegador usando LocalStorage.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage

## Como executar

1. Baixe ou clone este repositório.
2. Abra a pasta do projeto.
3. Abra o arquivo `index.html` em um navegador.

Não é necessário instalar dependências ou configurar um servidor.

## Estrutura dos arquivos

- `index.html`: estrutura da aplicação.
- `style.css`: estilos e layout responsivo.
- `script.js`: cadastro, cálculo e armazenamento das despesas.

## Observação

Os dados ficam salvos no LocalStorage do navegador utilizado. Limpar os dados do navegador pode apagar os registros.
